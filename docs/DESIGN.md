# GlyphOS Design Language

## Core principles

### 1. Black is a surface

- Background: `#000000`
- Primary text: `#F4F4F2`
- Secondary text: `#A9AAA7`
- Divider: `#2A2A28`

### 2. Typography does the work

Use large type, deliberate spacing, and a small number of type scales. Information should feel designed rather than densely packed.

### 3. Geometry over decoration

Use lines, circles, blocks, grids, and small indicators as functional visual elements. Avoid unnecessary gradients, glow effects, and decorative clutter.

### 4. Motion should communicate

Animations should explain state changes, not exist only for spectacle.

### 5. One expressive accent

A single accent color can be introduced by the user or derived from the active wallpaper. The base system remains monochrome.

## Interaction direction

The default workspace should feel comfortable for normal desktop users first. Keyboard-centric navigation and advanced Plasma behavior should remain available without forcing a tiling workflow.

## Inspiration boundary

GlyphOS can take inspiration from minimalist consumer technology, including Nothing's products, while all GlyphOS artwork, icons, UI components, code, and branding are independently created or used under compatible licenses.
